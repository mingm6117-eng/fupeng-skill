# 付鹏视角 · Skill

> 蒸馏付鹏（东北证券首席经济学家）的宏观-交易认知操作系统

基于女娲·Skill造人术方法论构建。

## 文件结构

```
fupeng-skill/
├── SKILL.md                    ← 核心，直接放入 ~/.claude/skills/
└── references/
    └── research-notes.md       ← 调研过程与三重验证记录
```

## 核心框架

- **三齿轮模型**（AJR框架）：生产力 × 生产关系 × 秩序
- **分子/分母/g因子**：任何资产分析的拆解工具
- **吃鸡缩圈**：风险偏好动态追踪
- **VIX期限结构**：击球点识别
- **哑铃型配置**：Beta + Alpha并持

## 安装

```bash
cp -r fupeng-skill ~/.claude/skills/
```
